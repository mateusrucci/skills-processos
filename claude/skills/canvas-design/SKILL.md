# Canvas Design

## Overview

Create static visual pieces as art objects, not generic layouts. Work in two phases: define a concise aesthetic movement in Markdown, then express that philosophy as a polished `.png` or `.pdf`.

## Workflow

1. Extract the user's visible request and the quieter conceptual thread underneath it.
2. Write a design philosophy in a `.md` file before making the canvas.
3. Translate that philosophy into one highly crafted visual composition unless the user asks for multiple pages.
4. Export the final piece as `.png` or `.pdf`, and keep the philosophy file alongside it.

## Design Philosophy Creation

Create a visual philosophy, not a page template. Treat it like a miniature manifesto for an art movement that can later be expressed visually.

Name the movement in 1-2 words.

Write 4-6 short paragraphs that define how the philosophy manifests through:
- space and form
- color and material
- scale and rhythm
- composition and balance
- visual hierarchy

Keep the philosophy specific enough to guide the piece, but open enough to leave room for interpretive design choices. Mention craftsmanship more than once; the resulting work should feel meticulous, expert, and labored over with care.

Emphasize these principles:
- communicate through space, form, color, and composition rather than explanatory text
- keep text sparse and treat it as a visual accent
- make the result feel like an art object rather than a decorated document
- avoid redundant aesthetic advice inside the philosophy

## Subtle Reference

Before designing the final piece, identify the subtle conceptual reference hidden inside the user's request. Use it as conceptual DNA rather than literal subject matter. Someone familiar with the topic should feel the reference; everyone else should still see a strong standalone composition.

Avoid obvious fan-art, imitation, or direct quotation of existing artists. Keep the result original and sophisticated.

## Canvas Creation

Create a single-page composition by default. Favor strong geometry, disciplined spacing, repeated motifs, layered textures, precise alignment, and a limited palette with intent.

Let the design philosophy control:
- how dense or quiet the page feels
- whether text whispers or lands as a bold gesture
- whether imagery is photographic, diagrammatic, abstract, or typographic
- how patterns, rhythm, and margins create tension or calm

Keep text minimal. Most of the communication should come from visual relationships, not paragraphs. If the user asks for a poster or campaign piece, allow more prominent text, but still make typography part of the composition rather than a block laid on top.

Do not let elements overlap accidentally or fall off the page. Maintain breathing room, margins, and clear hierarchy. Refinement matters more than adding more things.

## Typography and Fonts

Use varied, design-appropriate fonts when text appears. Prefer the bundled font set in `./assets/canvas-fonts`.

When choosing fonts:
- combine families intentionally instead of defaulting to one neutral sans
- match the emotional register of the philosophy
- prioritize readability only after visual intent and composition
- review the included license files before redistributing outputs that embed fonts

## Quality Bar

Push toward museum, magazine, or exhibition quality. The piece should feel as though an expert spent hours refining alignment, color, spacing, hierarchy, and finish.

Before finishing, take a second pass that refines what already exists instead of adding noise. Tighten spacing, improve contrast, simplify weak areas, and make the composition more coherent.

## Output Requirements

Always produce:
- one design philosophy `.md` file
- one final `.png` or `.pdf`

If the user asks for multiple pages, keep them within the same philosophy while making each page distinct.
