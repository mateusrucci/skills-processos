## 🏛️ Base regulatória

Suplementos alimentares no Brasil seguem:

| Norma | Cobertura |
|---|---|
| **RDC 243/2018** | Suplementos alimentares — composição, claims, rotulagem |
| **IN 28/2018** | Lista oficial de alegações nutricionais permitidas (claims verbatim) |
| **RDC 429/2020** | Rotulagem nutricional — "Alto teor de proteína", "Alto valor biológico" |
| **RDC 239/2018** | Suplementos de melatonina — dose máxima |

⚠️ **Regra de ouro:** claims ANVISA são **verbatim**. Parafrasear desfigura e perde a proteção regulatória. Use SEMPRE a redação literal da IN 28/2018.

## 🚨 Palavras-tabu (NUNCA usar)

### Tabu absoluto (acionam violação imediata)

| Palavra/expressão | Por quê |
|---|---|
| **anti-inflamatório** | Categoria farmacológica, não nutricional. Violação RDC 243/2018 |
| **anti-câncer / oncológico** | Claim médico, proibido para suplemento |
| **cura / trata** | Atribuição terapêutica |
| **detox / desintoxicação / limpeza** | Sem evidência científica reconhecida pela ANVISA |
| **fotoproteção / protetor solar** | Categoria de cosmético/medicamento |
| **emagrece X kg em Y dias** | Promessa quantificada não regulada |
| **substitui consulta médica** | Indução a erro |

### Tabu para temas sensíveis

| Tema | NÃO usar | Usar |
|---|---|---|
| **Sono** | "cura insônia", "trata distúrbio do sono" | "apoio ao ciclo natural do sono" |
| **Hormonal masculino** | "saúde sexual", "libido", "função erétil" | "vitalidade", "disposição" + claim Zn/testosterona |
| **Articulação** | "anti-inflamatório articular" | "modulação do estresse oxidativo articular" |

## 🔬 Auditoria de consistência (Falhas detectadas em 2026-05)

**Fonte:** `/Modernitty/Produtos/AUDITORIA-CONSISTENCIA.md`
**Nota geral:** 72/100 (estrutura excelente, mas 3 falhas sistêmicas)

### Falha #1 — "Anti-inflamatório" afirmativo
Aparece em ~8 dossiês de forma afirmativa:
- Imune AZ · Cúrcuma+K2 · Ácido Hialurônico · Puro Bronze · Fit Moderno · Whey · Creatina · Colágeno+AH+Vit C

**Violação:** RDC 243/2018. **Ação:** reescrever todas as menções.

### Falha #2 — Redações divergentes para o mesmo claim

**Zinco/imunidade — 5 variantes encontradas:**
- "auxilia o funcionamento" ✅ (correto)
- "contribui para o funcionamento" ✅ (alternativa válida)
- "fortalece" ❌ (não-verbatim)
- "sistema imune" ❌ (deveria ser "sistema imunológico")
- "imunidade" ❌ (não-verbatim)

**Cromo/metabolismo — 3 variantes:**
- "contribui para o metabolismo normal dos macronutrientes" ✅
- "ajuda o metabolismo" ❌
- "regula o metabolismo" ❌

### Falha #3 — Claims parafrasados em vez de VERBATIM

Sempre que possível, **copie literal** da IN 28/2018. Variação reduz proteção legal.
