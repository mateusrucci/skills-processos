> Combinações recomendadas entre os 20 produtos. Base científica + lógica de público + sinergia bioquímica + cuidado com sobreposições.

**Fonte canônica:** `/Modernitty/Produtos/CROSS-SELL.md` (cobra para detalhes científicos com DOIs)

---

## 🎯 Filosofia (3 princípios)

1. **Sinergia bioquímica real** — ingredientes se potencializam (ex: Vit C + Colágeno, D3 + K2, Whey + Creatina)
2. **Persona compartilhada** — produtos que cabem na rotina do MESMO cliente
3. **Evitar overlap** — NÃO recomendar dois produtos que entregam o mesmo benefício pelo mesmo mecanismo

## ⚠️ Combinações a EVITAR (overlap claro)

**NUNCA recomendar juntos** — cliente paga 2x pelo mesmo ativo:

| Combinação | Motivo |
|---|---|
| **AH cápsula + Colágeno+AH+Vit C (pó)** | Ambos têm AH 100mg |
| **Colágeno Hidrolisado + Colágeno+AH+Vit C** | Mesmo ativo principal |
| **Multi Homem/Mulher + Multi Sênior** | Mesmo target nutricional |
| **Imune AZ + Multi (qualquer)** | Overlap Vit C/D/Zn/Se (monitorar UL do Zn) |
| **Whey 80% + outra proteína em pó** | Overlap |
| **Creatina 3em1 + creatina pura adicional** | Overlap |
