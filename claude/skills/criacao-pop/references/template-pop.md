# Template POP — Visualização em Markdown

Este é o template em Markdown para **leitura humana / referência rápida**. Para gerar o POP oficial em .docx, use o script `scripts/generate_pop.py`.

---

| 01 - [Frase única começando com verbo no infinitivo descrevendo o que o POP garante.] |
