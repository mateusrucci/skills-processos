# Proposal Vibe Design

## Objetivo

Crie propostas com aparência de estúdio premium, não documentos corporativos genéricos. A base estética desta skill vem do banco:

- `/Users/mateusrucci/Downloads/Fundamentos de Vibe Design/Banco de Referências/Design Systems`
- `/Users/mateusrucci/Downloads/Fundamentos de Vibe Design/Banco de Referências/Sites para referência`

O resultado precisa parecer intencional, sofisticado e vendável.

## Quando usar

Use esta skill quando o usuário pedir:

- proposta comercial
- apresentação de serviços
- deck de vendas
- apresentação institucional
- proposta de site, branding, automação, IA ou produto digital
- material para enviar em `pptx` ou `pdf`

Se o pedido envolver apresentação, deck ou proposta, esta skill deve guiar a direção criativa mesmo quando outras ferramentas forem usadas para gerar o arquivo final.

## Formato de saída

Sempre entregue no formato que o usuário pedir:

- se pedir `pptx`, produza uma apresentação editável em formato de slides
- se pedir `pdf`, produza um documento ou deck finalizado para envio

Se o usuário não especificar, assuma `pdf`.

## Fluxo

1. Identifique a oferta, o público e o estágio da venda.
2. Converta isso em uma tese visual curta: 2 a 4 linhas sobre o tom da proposta.
3. Estruture a narrativa antes do layout.
4. Use o banco de referências como linguagem, não como modelo literal.
5. Entregue a proposta no formato solicitado pelo usuário.

## Estrutura narrativa padrão

Salvo instrução contrária, organize propostas em blocos como:

1. Capa com tese forte
2. Contexto ou oportunidade
3. Diagnóstico ou problema
4. Solução proposta
5. Escopo ou entregáveis
6. Processo, cronograma ou fases
7. Investimento
8. Fechamento com próximo passo

Para propostas curtas, compacte isso em 5 a 8 páginas.
Para propostas robustas, expanda para 10 a 16 páginas.

## Regras visuais

- Trate cada página como peça de direção de arte, não como slide padrão.
- Use grids claros, margens generosas e hierarquia forte.
- Misture tipografia de impacto com tipografia de apoio.
- Prefira poucas cores com muito controle de contraste.
- Use profundidade, camadas, blur, molduras, linhas, brilho e texturas com moderação.
- Faça a capa carregar o peso emocional do projeto.
- Faça páginas internas alternarem entre respiro editorial e densidade informacional.

## Vocabulário do banco

Priorize a linguagem sintetizada em `references/vibe-language.md`.

Em geral, o banco favorece:

- capas escuras ou neutras com tipografia grande
- superfícies translúcidas e bordas suaves
- grids aparentes, linhas verticais, separadores e frames
- tags monoespaçadas, microcopy técnico e labels discretos
- blocos modulares com alto refinamento
- contrastes entre brutalismo suave e polimento premium
- combinação de editorial, produto digital e visual tech

## Adaptação para proposta

Quando transformar isso em proposta:

- troque excesso de “UI demo” por clareza comercial
- mantenha a sofisticação, mas priorize leitura e persuasão
- use números, escopo e investimento com layout limpo e confiante
- evite páginas lotadas de texto corrido
- transforme listas em blocos, cards, tabelas enxutas ou composições modulares

## Restrições

- Não use visual de template genérico corporativo.
- Não use degradês aleatórios sem função compositiva.
- Não use ícones, mockups ou ornamentos apenas para “encher”.
- Não replique literalmente um site do banco.
- Não deixe a proposta parecer pitch de startup genérico se o pedido for mais institucional ou premium.

## Escolha de direção

Escolha uma das linhas abaixo conforme o contexto:

- `Dark Executive`: fundo escuro, alto contraste, ritmo cinematográfico, ideal para IA, produto, automação, software e posicionamento premium
- `Light Editorial`: fundo claro, estrutura de revista, serifada com sans, ideal para branding, estratégia, consultoria e proposta institucional
- `Hybrid Glass`: base sóbria com painéis translúcidos, ideal para tecnologia premium e ofertas modernas
- `Modular Grid`: blocos e cards precisos, ideal para escopo, roadmap, processo e investimento

## Conteúdo primeiro

Antes de desenhar, resolva:

- qual é a promessa central
- qual transformação está sendo vendida
- quais provas, entregáveis e próximos passos precisam aparecer

Se faltar conteúdo, faça a melhor suposição razoável e avance sem travar.
