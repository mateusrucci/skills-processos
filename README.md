# Skills e Processos

Repositorio central para skills pessoais do Codex e processos operacionais.

## Estrutura

- `skills/`: skills completas, cada uma em sua propria pasta com `SKILL.md` e, quando houver, `references/`, `scripts/` e `agents/`.
- `processos/`: documentos e processos avulsos que nao seguem necessariamente o formato de skill.
