## DNA visual

O banco aponta para um design que mistura:

- editorial premium
- interface de produto sofisticada
- visual tech com acabamento de marca
- ritmo de apresentação em cards, frames e páginas-capa

Não é minimalismo puro. Não é maximalismo caótico. É uma estética controlada, com contraste, profundidade e disciplina de grid.

## Paletas preferidas

### Escura

- preto, grafite, carvão e neutral profundo
- branco quente ou off-white para contraste
- um acento principal por proposta: laranja queimado, verde ácido controlado, azul elétrico, champagne ou prata fria

Use fundos escuros quando a proposta pedir:

- tecnologia
- IA
- automação
- software
- posicionamento premium

### Clara

- off-white, cinza névoa, areia fria, gelo, cinza claro
- texto em chumbo, grafite ou preto suave
- acentos contidos, nunca infantis

Use fundos claros quando a proposta pedir:

- institucional
- branding
- consultoria
- arquitetura de marca
- apresentação com mais leitura

## Tipografia

O banco sugere contraste entre famílias, não neutralidade total.

Combinações seguras:

- display geométrica ou grotesk para títulos + sans limpa para corpo
- serif editorial para títulos + sans funcional para corpo
- sans forte para títulos + mono para labels, números e navegação

Comportamentos:

- títulos curtos, grandes e muito bem espaçados
- subtítulos enxutos
- labels pequenos em mono, caixa alta ou tracking amplo
- corpo sempre respirando; nunca bloco compacto demais

## Composição

### Capa

A capa deve carregar a proposta quase sozinha.

Use:

- um título forte
- subtítulo ou tese curta
- um elemento dominante: frame, imagem, textura, gradiente, glow ou composição modular
- assinatura visual coerente com a oferta

### Miolo

Intercale páginas de:

- respiro editorial
- cards informacionais
- blocos de processo
- tabelas enxutas
- comparações lado a lado
- destaque de números ou entregáveis

Evite repetir o mesmo layout em todas as páginas.

## Componentes recorrentes

Componentes muito presentes no banco e úteis para propostas:

- painéis glass com blur leve
- bordas finas com gradiente
- cards com sombra suave e contraste alto
- linhas verticais e separadores aparentes
- grids com moldura ou colunas visíveis
- pequenos badges e pills
- fundos com glow radial ou textura sutil
- labels em mono com aparência de sistema

## Ritmo entre páginas

Mantenha alternância:

- uma página emocional
- uma página explicativa
- uma página modular
- uma página de credibilidade ou escopo

Esse ritmo evita que a proposta fique com cara de template repetido.

## Tradução para vendas

Quando o objetivo é fechar negócio:

- simplifique o experimentalismo
- mantenha a força estética
- faça a leitura chegar antes do efeito
- transforme conteúdo denso em estruturas modulares
- destaque investimento, fases e entregáveis com muita clareza

## Anti-padrões

Evite:

- template padrão com blocos azuis genéricos
- excesso de texto centralizado sem hierarquia
- mockups sem função
- degradês decorativos sem tensão visual
- ícones demais
- página branca vazia sem intenção
- visual de pitch de startup quando o projeto pede sofisticação institucional

## Regra prática de decisão

Se estiver em dúvida:

- aumente a qualidade da capa
- reduza a quantidade de texto
- fortaleça o grid
- escolha um único acento de cor
- use mais contraste tipográfico
- substitua lista comum por composição em módulos
